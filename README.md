# My Personal Portfolio

A responsive personal portfolio built with semantic HTML5 and an external CSS stylesheet
(CSS Grid, Flexbox and media queries). Hosted with GitHub Pages.

- `index.html` - page structure and content
- `style.css` - all styling (design tokens, layout, responsive rules)
- `images/profile.svg` - profile illustration
